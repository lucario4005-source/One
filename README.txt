DATAONE ANDROID APP - FIRST VERSION

This is the Android project source for Dataone. It contains buttons for Gmail, Google Photos, Google Drive, and Google Account. Tapping a button opens the corresponding Google service. It does not copy or store your Google data.

IMPORTANT: This ZIP is source code, not an already-built APK. The APK must be built using Android build tools.

Project files include the .github/workflows/build-apk.yml workflow used by GitHub Actions to build a debug APK. Keep the .github folder and its contents.

To edit the interface, edit app/src/main/java/com/viral/dataone/MainActivity.java. To change the app label, edit app/src/main/AndroidManifest.xml.
